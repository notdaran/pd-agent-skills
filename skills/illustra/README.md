# illustra

A Claude / agent **skill** that draws the illustration *inside* one marketing
card: a bento tile, an App Store feature card, a website feature block.

It blends two kinds of material on one canvas:

- **Real product screenshots**, framed and annotated. These are **pass-through
  pixels** - cropped, never redrawn, never regenerated by a model. What ships is
  your real UI.
- **Hand-drawn vector UI**, written as plain HTML / CSS / SVG: editor panels,
  score rings, drag-insert lines, A/B cards, selection frames, charts.

Output is a transparent retina PNG you drop onto the destination card.

![CRO Center and AEO drawer, real screenshots blended with vector UI mockups](./preview/aeo-card.webp)

Everything with a white panel above is a **real screenshot crop**, cut on a
whitespace gutter and embedded untouched. The dark "Add JSON-LD" and "Insert FAQ
section" windows beside them are **hand-drawn vector** - they show a flow that
has no screenshot yet. That mix is the whole point of the skill.

## What makes it more than a prompt

Three things live in the skill and get applied every time:

- **A component kit** (`components/`) - 23 reusable vector parts, each a self
  contained HTML snippet. New bespoke parts get harvested back into the kit when
  they are drawn a second time.
- **A style guide** (`references/style-guide.md`) - intake gates and 18 numbered
  composition rules (R1-R18), including an edge self-audit: every pair of
  adjacent edges must be a clear gap or a decisive overlap, never a
  near-parallel sliver.
- **An eval harness** (`evals/`) - scored runs so a change to the rules can be
  compared against a baseline instead of eyeballed.

The intake is deliberately conversational rather than a form: it asks where the
art will live, captures a neighbour card as reference, then picks a light or
dark-glass mode from that. A neighbour is treated as shared visual language,
never as a composition to clone.

## Not for

Multi-card page layouts. Animated sequences - use [`anima`](../anima) for those.
Photoreal or AI-generated imagery: illustra is vector plus framed real
screenshots, nothing else.

## Requirements

- Node.js >= 18

```bash
cd skills/illustra
npm install
npx playwright install chromium-headless-shell
```

> Both steps are needed. `npm install` pulls `playwright-core`, which
> `scripts/render.mjs` imports directly - a global install will not do, because
> Node does not resolve bare imports from the global prefix. The second command
> downloads the browser binary itself, which npm does not fetch.

## Install

Ships as part of [pd-agent-skills](../../README.md):

```bash
git clone https://github.com/notdaran/pd-agent-skills.git
cd pd-agent-skills
./install.sh
```

## Render

```bash
node scripts/render.mjs <canvas.html> outputs/<name>.png --width 1200 --height 900
```

Start from `templates/canvas.html` - a transparent stage with the brand preset
already wired.

## Brand

Colours, fonts and badge styling come from `references/brand.css`. Swap that one
file to render in a different brand; the drawing logic has no brand knowledge of
its own. PageFly is the preset that ships as the default.

See [`_pf-brand`](../_pf-brand) for the shared identity layer.

## Data

Nothing environment-specific lives in this skill - no paths, no credentials, no
project identifiers. The exception is deliberate: the images in `preview/` and
the PageFly values in `references/brand.css` are real product material, kept as
worked examples. The screenshots and the logo belong to their owner. Remove
them if you are not authorised to use them.
